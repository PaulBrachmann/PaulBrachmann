# Hi, I'm Paul!

I build for healthcare, climate, and education, a lot of it around medical imaging, offline-first sync, and sensitive data. Based in Berlin.

## Open source

**[Visian](https://github.com/HealthML/visian)** (Apache-2.0), Project lead\
A browser-based tool that lets medical researchers outline structures such as tumours in 3D scans (MRI, CT). I designed the architecture and co-built the WebGL rendering engine with volumetric ray tracing, along with "smart brush" tools that follow structural boundaries. Adopted at the Max Delbrück Center, Charité Berlin, Mount Sinai, and the WHO AI4Health Focus Group.

- Paper: [Interactive Volumetric Region Growing for Brain Tumor Segmentation on MRI using WebGL](https://dl.acm.org/doi/10.1145/3485444.3487640) (Web3D '21)
- [Demo video](https://youtu.be/6l8Et-bUGrE)

**[apollo-offline](https://github.com/Malpaux/apollo-offline)** (BSD-3-Clause), Author\
An offline-first toolkit for the Apollo GraphQL client. It allows apps to keep working without a connection and sync once the server is reachable again. Published when I was 17 (so please be kind!). Also contributed TypeScript declarations to [redux-offline](https://github.com/redux-offline/redux-offline/pull/112), which apollo-offline builds on.
